# 100 Days of Code Challenge

## Day 12 - Code 1

### Problem
Write a   program to calculate library fine based on late days as follows: 
     First 5 days late: ₹2/day 
     Next 5 days late: ₹4/day 
     Next 20 days days late: ₹6/day 
     More than 30 days: Membership Cancelled. 
     
### Code
The program takes the number of late days as input and calculates the library fine according to the given fine rates. If the book is returned after more than 30 days, the membership is cancelled.

## Day 12 - Code 2 

### Problem
Write a   program to calculate electricity bill based on units consumed with these   rates: 
     First 100 units at ₹5/unit 
     Next 100 units at ₹7/unit 
     Next 100 units at ₹10/unit 
     Above at ₹12/unit.

### Code
The program takes the number of electricity units consumed as input and calculates the total electricity bill according to the given unit-wise rates using if-else statements.
