# 100 Days of Code Challenge

## Day 31 - Code 1

### Problem
Reverse an array without taking extra space.

### Code
The program takes an array as input and reverses the array without using an extra array. It uses a temporary variable to swap elements from the beginning and end of the array.

## Day 31 - Code 2 

### Problem
Merge two arrays.

### Code 
The program takes two arrays as input from the user and merges them into a single array. It first copies the elements of the first array and then adds the elements of the second array.
