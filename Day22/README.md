# 100 Days of Code Challenge

## Day 22 - Code 1

### Problem
Write a program to check if a number is a strong number.

### Code
The program takes a number as input from the user and checks whether it is a Strong number by calculating the factorial of each digit and comparing their sum with the original number.

## Day 22 - Code 2 

### Problem
Write a program to find the sum of the series: 1 + 3/4 + 5/6 + 7/8 + … up to n terms.

### Code
The program takes the number of terms as input and calculates the sum of the series 1 + 3/4 + 5/6 + 7/8 + ... using a for loop.
