# 100 Days of Code Challenge

## Day 25 - Code 1

### Problem
Write a program to print the following pattern : 
     5
     45
     345
     2345
     12345
     
### Code
The program uses nested for loops to print a number pattern starting from 5 and decreasing the starting number in each row.
