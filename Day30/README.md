# 100 Days of Code Challenge

## Day 30 - Code 1

### Problem
Count positive, negative, and zero elements in an array.

### Code
The program takes the number of elements and their values as input, stores them in a one-dimensional array, and counts the positive, negative, and zero elements using a for loop.

## Day 30 - Code 2 

### Problem
Search for an element in an array using linear search.

### Code 
The program takes array elements and a search element as input from the user and searches for the element using linear search. It displays the position if the element is found; otherwise, it displays that the element is not found.
