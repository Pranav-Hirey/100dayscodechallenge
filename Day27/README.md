# 100 Days of Code Challenge

## Day 27 - Code 1

### Problem
Write a program to print the following pattern : 
     
        *
       ***
      *****
     *******
      *****
       ***
        *

          
### Code
The program uses nested for loops to print a centered diamond pattern of stars. The number of stars increases from 1 to 7 and then decreases back to 1, with spaces used to center the pattern.

## Day 27 - Code 2 

### Problem
Write a program to print all the prime numbers from 1 to n.

### Code 
The program takes a number n as input from the user and prints all the prime numbers from 1 to n using nested for loops.
