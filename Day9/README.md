# 100 Days of Code Challenge

## Day 9 - Code 1

### Problem
Write a program to find the roots of a quadratic equation and categorize them.

### Code
The program takes the coefficients of a quadratic equation as input and finds and categorizes its roots as real and different, real and equal, or complex using the discriminant.

## Day 9 - Code 2 

### Problem
Write a   program that accepts a percentage (0-100) and assigns a grade based on the   following criteria: 
     90-100: Grade A 
     80-89: Grade B 
     70-79: Grade C 
     60-69: Grade D 
     below 60: Grade F.

### Code
The program takes a percentage between 0 and 100 as input and assigns a grade from A to F based on the given percentage criteria using if-else statements.
