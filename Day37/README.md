# 100 Days of Code Challenge

## Day 37 - Code 1

### Problem
Find the transpose of a matrix.

### Code
The program takes a matrix as input from the user and finds its transpose. In the transpose, the rows of the original matrix become columns and the columns become rows.

## Day 37 - Code 2 

### Problem
Add two matrices.

### Code 
The program takes two matrices of the same size as input and adds their corresponding elements. The result is stored in a third matrix and displayed.
