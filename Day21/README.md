# 100 Days of Code Challenge

## Day 21 - Code 1

### Problem
Write a program to swap the first and last digit of a number.

### Code
The program takes a number as input from the user and swaps its first and last digits using a while loop.

## Day 21 - Code 2 

### Problem
Write a program to check if a number is a perfect number.

### Code
The program takes a number as input from the user and checks whether it is a perfect number by finding the sum of its proper factors using a for loop.
